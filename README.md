# Portfólio HUB

> **NON DUCOR, DUCO.**

Meu portfólio pessoal desenvolvido durante minha formação em programação pelo **Jovem Tech**.

O Portfólio HUB foi criado para reunir meus projetos, tecnologias, competências e minha trajetória como desenvolvedor em um único espaço.

## ✦ Sobre o projeto

A proposta do Portfólio HUB é ir além de uma apresentação convencional.

Busquei criar uma identidade visual própria, inspirada em uma estética **gótica industrial e vitoriana**, utilizando elementos como madeira escura, metal envelhecido, detalhes dourados e iluminação cinematográfica.

A identidade visual também representa uma ideia importante para minha trajetória: **construção e evolução**.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 📂 Projetos

### Pomodoro Focus

Aplicação de produtividade baseada na técnica Pomodoro, desenvolvida para auxiliar períodos de foco e descanso.

**Tecnologias:** HTML5 • CSS3 • JavaScript

**Status:** Concluído

### Lies of P

Projeto de experiência visual inspirado no universo de *Lies of P*, explorando composição visual, navegação, transições e interações com JavaScript.

**Tecnologias:** HTML5 • CSS3 • JavaScript

**Status:** Em desenvolvimento

### Registro de Atividades

Sistema desenvolvido para registrar atividades, níveis de complexidade e datas de entrega.

**Tecnologias:** HTML5 • CSS3 • JavaScript

**Status:** Em finalização

## ⚙️ Recursos

- Página única com navegação por seções
- Menu responsivo
- Navegação ativa conforme a seção atual

- Fundos dinâmicos por seção

## 🎨 Identidade

A estética do projeto foi inspirada na atmosfera visual de *Lies of P*, utilizando uma combinação de elementos:

- Arquitetura vitoriana
- Estética industrial
- Elementos góticos
- Metal e madeira envelhecidos
- Tons escuros
- Dourado envelhecido
- Iluminação cinematográfica

A inspiração é exclusivamente visual. O objetivo é utilizar essa linguagem para representar minha própria trajetória como desenvolvedor.
